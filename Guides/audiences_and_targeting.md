# Audiences and Targeting

Optimize your programmatic advertising by building and refining your audience. This overview provides insights into creating audiences using data elements and data groups within the API platform.

Audiences are specific groups for campaigns, created by combining data groups with included and excluded elements. Data elements include:

*   First-party segments, ideally sourced from a seed.
*   Third-party segments (like cookies, IDs, or alternatives like contextual and location-based data.)

By combining these data groups and elements, you can tailor your targeting to reach a wider or more specific audience.
