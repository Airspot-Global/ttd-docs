# Platform Management

This page outlines and provides support guidelines to facilitate the management process for the Platform API.

The following are used to manage Platform API usage by clients and The Trade Desk.

*   [Activity Logs](#logs): View logs of user activity.
*   [Platform Synchronization](#synchronization): View changes over time.
*   [Planned Maintenance Schedule](#maintenance): Regularly scheduled downtime.

## 

Activity Logs[](#logs)

View logs of user REST API activity for all basic create, read, update, and delete operations. Use the information to determine bad requests and apply [strict mode](/v3/portal/api/doc/StrictMode) constraints.

To turn on activity logs for your REST endpoints and users, see [Activity Logs](/v3/portal/api/doc/ActivityLog).

## 

Platform Synchronization[](#synchronization)

Sync changes by comparing versions between set time windows using deltas in GraphQL and REST.

For details on making a synchronization request in REST and GraphQL, see [Platform Synchronization](/v3/portal/api/doc/PlatformSynchronization).

## 

Planned Maintenance Schedule[](#maintenance)

During maintenance, the Platform API and related functions are down. This happens on every third Friday of the month and can last for up to an hour or more, starting from 7:00 PST. For details, see our [Planned Maintenance Schedule](/v3/portal/api/doc/PlannedMaintenanceSchedule).
