# Platform management

This page outlines and provides support guidelines to facilitate the management process for the Platform API.

The following are used to manage Platform API usage by clients and The Trade Desk.

- Activity Logs: View logs of user activity.
- Platform Synchronization: View changes over time.
- Maintenance Schedule: Regularly scheduled downtime.

## Activity logs

View logs of user REST API activity for all basic create, read, update, and delete operations. Use the information to determine bad requests and apply Strict mode constraints.

To turn on activity logs for your REST endpoints and users, see Activity logs.

## Platform synchronization

Sync changes by comparing versions between set time windows using deltas in GraphQL and REST.

For details on making a synchronization request in REST and GraphQL, see Platform synchronization.

## Maintenance schedule

During maintenance, the Platform API and related functions are down. This happens on every third Friday of the month and can last for up to an hour or more, starting from 7:00 PST. For details, see our Maintenance schedule.
