# POST /v3/audience/query/advertiser → Advertiser.audiences

## Overview

| Property | Value |
| --- | --- |
| REST endpoint | `POST /v3/audience/query/advertiser` |
| GraphQL query | `Advertiser.audiences` |
| Return type | `AudiencesConnection` |

## Request and filter field mapping

| REST field | GraphQL argument | GraphQL type | Required | Notes |
| --- | --- | --- | --- | --- |
| `AdvertiserId` | Parent: `Query.advertiser(id: ID!)` | N/A | Required | Enter via `advertiser(id: "<advertiser-id>") { audiences(...) }`. |
| `SearchTerms` | `where` | AudienceFilterInput | Optional | Map each term to `name`, `id`, or `description` filters (e.g. `where: { name: { contains: "retail" } }`). REST requires every term to match across ID/name/description. |
| `SortFields` | `order` | [AudienceSortInput!] | Optional | Sort keys: `id`, `name`, `description`, `lastUpdatedAt`. |
| `PageStartIndex` | `after` | String | Optional | N/A |
| `PageSize` | `first` | Int | Optional | N/A |

## Code examples

### REST example

```
POST /v3/audience/query/advertiser HTTP/1.1
Content-Type: application/json
TTD-Auth: AUTH_TOKEN_PLACEHOLDER

{
  "AdvertiserId": "<advertiser-id>",
  "SearchTerms": ["retail"],
  "PageStartIndex": 0,
  "PageSize": 25
}
```

### GraphQL example

```
POST /graphql HTTP/1.1
Content-Type: application/json
TTD-Auth: AUTH_TOKEN_PLACEHOLDER
```

```
query AdvertiserAudiences {
  advertiser(id: "<advertiser-id>") {
    audiences(
      first: 25
      where: { name: { contains: "retail" } }
    ) {
      nodes {
        id
        name
        description
        lastUpdatedAt
        isAutoGenerated
      }
      totalCount
      pageInfo {
        hasNextPage
        endCursor
      }
    }
  }
}
```
