gql[campaignCreate Mutation](/v3/portal/api/gql-doc/campaign-create)

Create a new campaign.

gql[campaign Query](/v3/portal/api/gql-doc/campaign)

Get an existing campaign by ID.

gql[campaigns Query](/v3/portal/api/gql-doc/campaigns)

Get existing campaigns.

gql[campaignUpdate Mutation](/v3/portal/api/gql-doc/campaign-update)

Update a campaign.

gql[campaignBudgetSettingsUpdate Mutation](/v3/portal/api/gql-doc/campaign-budget-settings-update)

Updates the campaign budget settings.

gql[campaignClonesCreate Mutation](/v3/portal/api/gql-doc/campaign-clones-create)

Clones the specified campaigns and their components. Returns an ID that can be used to track the progress of each job created as a result.To use this mutation, you must have access to Kokai.

gql[campaignAssociateBidList Mutation](/v3/portal/api/gql-doc/campaign-associate-bid-list)

Associate or remove bid lists from a campaign and enable or disable them for bidding.

gql[campaignVersionUpgrade Mutation](/v3/portal/api/gql-doc/campaign-version-upgrade)

Upgrades the specified campaigns, performing necessary migrations in the process.

post[/v3/campaign/clone](/v3/portal/api/ref/post-campaign-clone)legacy

This is a legacy endpoint. Use the [`campaignClonesCreate` mutation](/v3/portal/api/gql-doc/campaign-clones-create) in GraphQL for improved performance and expanded functionality.

Submits a job to clone a campaign.  
**IMPORTANT**: Here's what you need to know about this endpoint:

*   The API does not wait for the clone process to complete.
*   You can check outcome of the cloning process by calling the [GET /campaign/clone/status/{referenceId}](/v3/portal/api/ref/get-campaign-clone-status-referenceid) endpoint.
*   The URL, including the `ReferenceId`, is also given in the Location header.
*   You may not use this endpoint to clone campaigns with more than 500 ad group.
*   If the campaign to be cloned has Advanced Frequency Settings configured, they will not be cloned. To avoid unintentional spend, be sure to update your cloned campaign frequency settings accordingly.

post[/v3/campaign/template/clone](/v3/portal/api/ref/post-campaign-template-clone)

Submits a job to clone a campaign. The API does not wait for the clone process to complete.  
You can check outcome of the cloning process by calling the [GET /campaign/clone/status/{referenceId}](/v3/portal/api/ref/get-campaign-clone-status-referenceid) endpoint.  
The URL, including the `ReferenceId`, is also given in the Location header.  
NOTE: You may not use this endpoint to clone campaigns with more than 500 ad group.

post[/v3/campaign/template/query/advertiser](/v3/portal/api/ref/post-campaign-template-query-advertiser)

Get a page of Campaign templates that belong to the specified Advertiser.
