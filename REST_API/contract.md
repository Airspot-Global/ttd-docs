Contract

post[/v3/contract](/v3/portal/api/ref/post-contract)

Create a new Contract.

put[/v3/contract](/v3/portal/api/ref/put-contract)

Update an existing Contract.

post[/v3/contract/buyers/query/advertisers](/v3/portal/api/ref/post-contract-buyers-query-advertisers)

Query for Advertisers that may act as buyers of Contracts offered by the chosen Partner.  
These are the Advertisers that may be specified in ContractPermissions of the Partner's Contracts.

post[/v3/contract/buyers/query/partners](/v3/portal/api/ref/post-contract-buyers-query-partners)

Query for info about all the Partners that may act as buyers for Contracts offered by the chosen Partner.  
These are the Partners that may be specified in the ContractsPermissions of the Partner's Contracts.

get[/v3/contract/{contractId}](/v3/portal/api/ref/get-contract-contractid)

Get an existing Contract.

get[/v3/contract/name/{contractId}](/v3/portal/api/ref/get-contract-name-contractid)

Get the identifier and name for a Contract based on identifier

post[/v3/contract/query/advertiser/available](/v3/portal/api/ref/post-contract-query-advertiser-available)

Query for a page of Contracts that are available for the chosen Advertiser to buy.

post[/v3/contract/query/deliveryprofile](/v3/portal/api/ref/post-contract-query-deliveryprofile)

Query for a page of Contracts that are associated with specified DeliveryProfileId

get[/v3/contract/query/facets](/v3/portal/api/ref/get-contract-query-facets)

Get the facets of Contracts that can be used in queries.

post[/v3/contract/query/partner](/v3/portal/api/ref/post-contract-query-partner)

Query for a page of Contracts owned by a Partner.

post[/v3/contract/query/partner/available](/v3/portal/api/ref/post-contract-query-partner-available)

Query for a page of Contracts that are available to the Advertisers under the chosen Partner.

post[/v3/contract/query/supplyvendordeal](/v3/portal/api/ref/post-contract-query-supplyvendordeal)

Query for a page of Contracts associated with the specific SupplyVendorDealId

post[/v3/contract/report/impressions/available](/v3/portal/api/ref/post-contract-report-impressions-available)

Query for a page of an Available Impressions Report for a specific Contract.
