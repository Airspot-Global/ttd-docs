## Operations and endpoints

### GET /v3/redsfeed/{feedId}

Reference: https://open.thetradedesk.com/advertiser/docsApp/AdvertiserReferences/api/ref/get-redsfeed-feedid

Gets a list of all columns for the feed ID

### POST /v3/redsfeed/query

Reference: https://open.thetradedesk.com/advertiser/docsApp/AdvertiserReferences/api/ref/post-redsfeed-query

Gets metadata of all available feeds

### GET /v3/reds/impressions/facets

Reference: https://open.thetradedesk.com/advertiser/docsApp/AdvertiserReferences/api/ref/get-reds-impressions-facets

Gets a list of all enumeration maps for the Raw Event Data Stream Impression event type

### GET /v3/reds/video/facets

Reference: https://open.thetradedesk.com/advertiser/docsApp/AdvertiserReferences/api/ref/get-reds-video-facets

Gets a list of all enumeration maps for the Raw Event Data Stream Video event type that the specified requester is authorized to view
