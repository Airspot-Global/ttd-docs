gql[adGroupDelta Query](/v3/portal/api/gql-doc/ad-group-delta)

Get all changed ad groups for an advertiser or campaign since the last change-tracking version.

gql[campaignDelta Query](/v3/portal/api/gql-doc/campaign-delta)

Get all changed campaigns for an advertiser since the last change-tracking version.

gql[creativeDelta Query](/v3/portal/api/gql-doc/creative-delta)

Get all changed creatives for an advertiser since the last change-tracking version.

gql[trackingTagDelta Query](/v3/portal/api/gql-doc/tracking-tag-delta)

Get all changed tracking tags for an advertiser since the last change-tracking version.

post[/v3/delta/activity/query/adgroup](/v3/portal/api/ref/post-delta-activity-query-adgroup)

Retrieve a list of IDs of all activity logs for the specified ad group that were updated since the last change tracking version.  
**TIP**: With GraphQL, you can significantly improve performance, tailor queries to specific criteria, and save both time and effort. To get started, use the [Delta Python scripts](https://github.com/thetradedesk/Platform/tree/main/Python/Delta). See also [Platform Synchronization](/v3/portal/api/doc/PlatformSynchronization).

post[/v3/delta/dmp/query/advertiser/firstparty](/v3/portal/api/ref/post-delta-dmp-query-advertiser-firstparty)

Retrieve a list of IDs of all first-party data segments that were modified since the last change tracking version. For details, see [delta endpoints](/v3/portal/api/doc/PlatformSynchronization#delta-endpoints).  
**NOTE**: This endpoint returns only newly created segments and those with updated metadata, such as changes to names or descriptions. Segments with updated user data, such as user counts, are not returned.
