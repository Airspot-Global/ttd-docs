## Operations and endpoints

### POST /v3/frequency/counter

Reference: https://open.thetradedesk.com/advertiser/docsApp/AdvertiserReferences/api/ref/post-frequency-counter

Create a frequency counter, return the created counter.

### PUT /v3/frequency/counter

Reference: https://open.thetradedesk.com/advertiser/docsApp/AdvertiserReferences/api/ref/put-frequency-counter

Update a frequency counter, returning the updated counter.

### GET /v3/frequency/counter/{counterId}

Reference: https://open.thetradedesk.com/advertiser/docsApp/AdvertiserReferences/api/ref/get-frequency-counter-counterid

Gets the frequency counter definition

### POST /v3/frequency/counter/query

Reference: https://open.thetradedesk.com/advertiser/docsApp/AdvertiserReferences/api/ref/post-frequency-counter-query

Retrieve a paged, sorted, and filterable list of frequency counters for a specific advertiser or partner.
